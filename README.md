# dotfiles

The active configuration is on `main`. The previous Chimera configuration is preserved on `pre-arch` (the older Fedora setup is on `fedora`).

From this checkout, preview the Sway links with `python3 scripts/link-sway.py`, then install with `python3 scripts/link-sway.py --apply`.
Use `--backup-conflicts` to preserve existing files before replacing them; keep this checkout in its permanent location.
